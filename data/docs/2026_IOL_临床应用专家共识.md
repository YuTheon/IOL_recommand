# 2026年白内障人工晶状体植入临床专家共识（测试版）

## 1. 眼轴长度（AL）与预留屈光度指南
在进行白内障超声乳化联合人工晶状体植入术时，眼轴长度是决定术后目标屈光度的核心指标：
- **短眼轴（AL ≤ 22.0 mm）**：通常伴随远视。建议术后目标屈光度预留 +0.5D 至 0D，以获得最佳远视力。若植入多焦点晶体，需严格评估前房深度。
- **正常眼轴（22.0 mm < AL ≤ 26.0 mm）**：若患者选择单焦点晶状体，建议预留 -0.5D 至 0D；若患者选择多焦点或EDOF晶体，目标屈光度应尽量设定为正视（0D）。
- **长眼轴（AL > 26.0 mm）**：高度近视患者。为了适应患者原有的用眼习惯，单焦点晶状体建议预留 -2.0D 至 -3.0D 的近视度数。此类患者眼底病变风险高，一般不建议植入多焦点人工晶状体。

## 2. 散光矫正原则
- 当患者术前角膜规则散光大于 0.75D 时，强烈建议在条件允许的情况下植入散光矫正型（Toric）人工晶状体，以提高术后脱镜率。
- 若不选用 Toric 晶体，散光将严重影响多焦点晶状体的光学表现，导致视觉质量下降。

## 3. 等效球镜（SE）与多焦点的选择
- 若术前评估 SE 值偏远视（如 SE ≥ 1.0D），多焦点 IOL 的附加度数可适当偏小，或优先考虑植入景深延长型（EDOF）晶状体。
- 若术前评估 SE 值偏近视（如 SE ≤ -3.0D），患者通常对近视力要求较高，建议选择附加度数较大的多焦点 IOL（如 +3.0D 甚至 +3.25D）。
